# SSH Key-based Login

- Received SSH private key with passphrase for secure login.  
- Cloned GitLab repository and imported the provided Docker image.  
- Logged into the Docker container using the SSH key authentication.  
- Executed the `my-hash` command inside the container to generate an encrypted message.  
- Saved the message to `ssh-my-hash-1.txt` and uploaded it to Einstein for verification.  
- Gained practical experience with SSH key-based authentication and Docker container access.
